## DH 参数转换

| Joint | a (m)   | alpha (rad) | d (m)    | theta |
|-------|---------|-------------|----------|-------|
| 1     | 0       | 0           | 0.1765   | θ1    |
| 2     | 0       | π/2         | 0        | θ2+π/2|
| 3     | 0.607   | 0           | 0        | θ3    |

| 5     | 0       | π/2         | 0.125    | θ5    |

## 连杆长度
- Link0 (基座高度): 0.1765 m = 176.5 mm
- Link1 (肩部到肘部): 0.607 m = 607 mm
- Link2 (肘部到腕部): 0.568 m = 568 mm
- Link3 (腕部偏移): 0.191 m = 191 mm (垂直方向)
- Link4 (手腕1长度): 0.125 m = 125 mm
- Link5 (手腕2长度): 0.1084 m = 108.4 mm

## 与当前代码的对比

当前 `mm.cpp` 中使用的 UR5 参数：
```cpp
case ManiType::UR5:
case ManiType::CR10: {
    dh_alpha << 1.570796327, 0, 0, 1.570796327, -1.570796327, 0;
    dh_a << 0, -0.425, -0.39225, 0, 0, 0;
    dh_d << 0.089159, 0, 0, 0.10915, 0.09465, 0.0823;
    dh_theta_offset << 0, 0, 0, 0, 0, 0;
    break;
}
```

**关键差异：**
1. **dh_a** (连杆长度): 当前使用 UR5 的 [0.425, 0.39225]，应该是 CR10 的 [0.607, 0.568]
2. **dh_d** (连杆偏移): 当前使用 UR5 的值，需要更新为 CR10 的 [0.1765, 0, 0, 0.191, 0.125, 0.1084]
3. **dh_theta_offset**: Joint2 和 Joint4 需要偏移
